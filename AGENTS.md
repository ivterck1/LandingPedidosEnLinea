# Landing Pedidos en Línea

## Objetivo

Crear una landing page para un restaurante donde los clientes puedan:

- Consultar el menú.
- Seleccionar platillos.
- Elegir cantidades.
- Agregar notas.
- Indicar su nombre.
- Elegir entrega a domicilio o recoger.
- Ver el total del pedido.
- Enviar el pedido por WhatsApp.

## Tecnologías

- HTML5
- CSS3
- JavaScript puro
- Sin frameworks
- Sin backend en la primera versión

## Reglas del proyecto

- Diseño mobile-first.
- Código limpio y fácil de entender.
- Nombres de variables y funciones claros.
- Separar estructura, estilos, datos y lógica.
- Evitar código duplicado.
- Explicar los cambios realizados.
- No implementar cambios grandes sin aprobación.
- Mantener accesibilidad básica.
- Validar los datos antes de enviar el pedido.

## Estilo visual

- Diseño moderno y cálido.
- Enfocado en alimentos y pedidos rápidos.
- Buena legibilidad.
- Botones grandes y cómodos para celular.
- Carrito visible y fácil de usar.
