# 11 — UI Design

## Estado

Fase iniciada. Sistema visual y especificación de pantallas v1 preparados para revisión.

## Objetivo

Transformar los wireframes aprobados en una interfaz de alta fidelidad coherente, responsiva y lista para implementación, usando **Antojo Inmediato** como dirección visual oficial.

## Fuente de verdad

1. Phase 09 define el lenguaje visual.
2. Phase 10 define arquitectura, comportamiento y flujo.
3. Phase 11 unifica ambos sin copiar errores o inconsistencias de imágenes generadas.

## Decisiones heredadas

- Una sola landing.
- Menú completo de aproximadamente 30 productos en seis categorías.
- Desktop con carrito sticky; mobile con barra de pedido fija.
- WhatsApp solo después de validar y revisar el pedido.
- Los datos comerciales no confirmados permanecen marcados como pendientes.

## Regla de avance

No comienza la implementación hasta aprobar el sistema visual, las vistas desktop/mobile y el contenido mínimo necesario.
