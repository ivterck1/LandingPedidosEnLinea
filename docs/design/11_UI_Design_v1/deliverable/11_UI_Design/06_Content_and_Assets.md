## Datos provisionales permitidos en UI Design

Se pueden usar productos de muestra claramente marcados como contenido provisional para evaluar jerarquía y longitud. No deben convertirse automáticamente en datos de producción.

## Fuente de datos recomendada

Un único catálogo estructurado con:

`id`, `name`, `description`, `category`, `price`, `available`, `image`, `featured`.

Esta misma fuente alimentará tarjetas, carrito, total y mensaje de WhatsApp.

## Criterio de fotografía

Si no existe fotografía homogénea, conviene diseñar y presupuestar una sesión de producto. Mezclar imágenes con luces, fondos y calidades incompatibles debilitaría la identidad más que una solución editorial consistente sin foto para algunos artículos.
