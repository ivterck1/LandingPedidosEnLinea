# 07 — UI Approval Checklist

## Identidad

- [ ] La interfaz se reconoce como Antojo Inmediato.
- [ ] Navy, crema, naranja y verde tienen funciones claras.
- [ ] La decoración marina acompaña sin saturar.
- [ ] La fotografía se siente fresca, honesta y coherente.

## Contenido y catálogo

- [ ] Se entienden las seis categorías y la categoría activa.
- [ ] Los 30 productos caben en el sistema sin mostrar todos a la vez.
- [ ] Nombre, descripción, precio y disponibilidad son legibles.
- [ ] Agregar y modificar cantidades es evidente.

## Pedido

- [ ] Carrito, cantidades, subtotales y total coinciden.
- [ ] Entrega y recolección muestran solo sus campos relevantes.
- [ ] Los errores explican cómo corregirlos.
- [ ] La revisión previa coincide con el mensaje de WhatsApp.
- [ ] La interfaz no afirma que WhatsApp ya envió el pedido.

## Responsivo y accesibilidad

- [ ] Desktop, tablet y mobile conservan jerarquía.
- [ ] La barra móvil no tapa contenido.
- [ ] Se puede completar el pedido con teclado.
- [ ] Contraste, foco y tamaños táctiles cumplen mínimos.
- [ ] Estados vacío, agotado, error y carga están diseñados.

## Cierre

Phase 11 se aprueba cuando las vistas de alta fidelidad desktop y mobile cumplen esta lista y el contenido provisional está claramente separado del contenido confirmado.
