# 03 Hero Desktop - Antojo Inmediato

## 1. Creative Brief

Explore a desktop hero that creates immediate appetite and sends users toward ordering.

## 2. Art Direction

Bold headline, close seafood photography, immediate price or product cue, high-contrast CTA and short supporting copy.

## 3. UX Requirements

Primary CTA "Pedir ahora"; secondary CTA "Ver menu"; no distraction from conversion.

## 4. Required Sections

Header and Hero only.

## 5. Content Guidance

Use "Mariscos frescos listos para pedir" and visible CTA labels.

## 6. Technical Mockup Requirements

Flat desktop hero, no browser chrome, no device, no perspective.

## 7. Negative Prompt

No generic delivery template, no browser UI, no lorem ipsum, no cartoon graphics, no device frame.

## 8. GPT Image Adapter

Request a high-impact food hero with readable Spanish CTAs and product-first hierarchy.

## 9. Midjourney Adapter

Use `--ar 16:9`; specify bold front-facing restaurant hero, no device.

## 10. Flux Adapter

Request immediate appetite hero, large CTA and realistic seafood photography.

## 11. Output Filename

`mockups/03-hero-desktop.webp`
