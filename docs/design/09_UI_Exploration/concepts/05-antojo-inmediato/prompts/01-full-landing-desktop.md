# 01 Full Landing Desktop - Antojo Inmediato

## 1. Creative Brief

Create a full desktop landing mockup for El Cangrejo Cevichero using the Antojo Inmediato concept. The business goal is maximum conversion to WhatsApp ordering.

## 2. Art Direction

Bold food-first layout, strong CTAs, high-impact seafood photography, fast section rhythm, visible prices and prominent cart/order areas.

## 3. UX Requirements

The page must reduce hesitation: see dish, add product, review total, complete form and send WhatsApp. Every section supports action.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use realistic Spanish content: "Se te antojo? Pidelo ahora", "Agregar", "Total visible", Ceviche Explosivo $170 MXN, Tostada Crunch $105 MXN, Coctel Grande $180 MXN.

## 6. Technical Mockup Requirements

Front-facing complete vertical landing, long portrait ratio around 9:16 or taller, no browser chrome, no device, no perspective, no presentation board.

## 7. Negative Prompt

No browser UI, no device, no fake delivery app clone, no lorem ipsum, no hidden CTA, no missing cart, no cropped sections.

## 8. GPT Image Adapter

Request a full landing mockup with bold conversion-oriented seafood ordering and readable Spanish CTAs.

## 9. Midjourney Adapter

Use `--ar 9:16`; specify flat front-facing high-conversion restaurant landing, no device, no browser.

## 10. Flux Adapter

Request bold product-first layout, prominent prices, cart and WhatsApp CTA.

## 11. Output Filename

`mockups/05-full-landing-desktop.webp`
