# 04 Menu Section - Antojo Inmediato

## 1. Creative Brief

Explore a high-conversion menu section optimized for fast selection.

## 2. Art Direction

Bold product cards, strong image crops, large prices, obvious add buttons and compact category navigation.

## 3. UX Requirements

Users must be able to scan products and add quickly. Price and "Agregar" must be visually immediate.

## 4. Required Sections

Categories and Menu preview.

## 5. Content Guidance

Use Ceviche Rojo $160 MXN, Tostada Campechana $115 MXN, Coctel Grande $180 MXN, Agua Fresca $45 MXN.

## 6. Technical Mockup Requirements

Front-facing section mockup, no device, no perspective, no cropped cards.

## 7. Negative Prompt

No hidden prices, no missing add buttons, no lorem ipsum, no random fast food, no cluttered app clone.

## 8. GPT Image Adapter

Request bold seafood menu cards with very clear prices and add buttons.

## 9. Midjourney Adapter

Use `--ar 4:5`; specify flat menu UI, conversion-focused, readable prices.

## 10. Flux Adapter

Request fast-scanning product grid, category controls and prominent CTAs.

## 11. Output Filename

`mockups/04-menu-section.webp`
