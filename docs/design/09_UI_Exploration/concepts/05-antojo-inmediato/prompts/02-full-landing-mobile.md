# 02 Full Landing Mobile - Antojo Inmediato

## 1. Creative Brief

Create a complete mobile landing for Antojo Inmediato. It should help a hungry user order quickly with minimal reading.

## 2. Art Direction

One-column high-conversion flow, large buttons, strong food images, compact product cards, visible cart and sticky-feeling WhatsApp priority.

## 3. UX Requirements

Large touch targets, immediate add buttons, visible total, cart access and clear WhatsApp CTA. No extra decorative sections.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use "Pedir ahora", "Agregar", "Tu carrito", "Total $330 MXN", "Listo para WhatsApp", realistic seafood names and prices.

## 6. Technical Mockup Requirements

Front-facing mobile landing, 9:16, no phone frame, no hand, no perspective, no horizontal overflow.

## 7. Negative Prompt

No phone mockup, no unreadable text, no generic fast food template, no hidden total, no cropped sections.

## 8. GPT Image Adapter

Ask for a flat mobile high-conversion seafood ordering page without device frame.

## 9. Midjourney Adapter

Use `--ar 9:16`; specify mobile-first bold restaurant ordering UI, no phone, no hand.

## 10. Flux Adapter

Request fast one-column order flow, product cards, cart and WhatsApp CTA.

## 11. Output Filename

`mockups/02-full-landing-mobile.webp`
