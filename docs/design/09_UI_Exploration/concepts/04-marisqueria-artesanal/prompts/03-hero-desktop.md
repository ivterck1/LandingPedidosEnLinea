# 03 Hero Desktop - Marisqueria Artesanal

## 1. Creative Brief

Explore the desktop hero for a warm handcrafted seafood restaurant.

## 2. Art Direction

Prepared seafood, ingredient detail, human warmth, honest headline and practical CTAs.

## 3. UX Requirements

Primary CTA "Pedir por WhatsApp"; secondary CTA "Ver menu"; clear brand promise around preparation.

## 4. Required Sections

Header and Hero only.

## 5. Content Guidance

Use "Mariscos frescos preparados al momento" and short text about recipes, freshness and easy ordering.

## 6. Technical Mockup Requirements

Flat desktop hero, no browser chrome, no device, no perspective.

## 7. Negative Prompt

No rustic restaurant cliche, no unreadable text, no device frame, no lorem ipsum, no cartoon seafood.

## 8. GPT Image Adapter

Request a warm hero section with prepared seafood photography and clear ordering CTAs.

## 9. Midjourney Adapter

Use `--ar 16:9`; specify front-facing website hero, artisanal seafood, no browser UI.

## 10. Flux Adapter

Request a handcrafted seafood hero with readable Spanish text and WhatsApp CTA.

## 11. Output Filename

`mockups/03-hero-desktop.webp`
