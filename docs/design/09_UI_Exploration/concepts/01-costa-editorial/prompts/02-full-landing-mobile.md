# 02 Full Landing Mobile - Costa Editorial

## 1. Creative Brief

Create a complete mobile landing mockup for El Cangrejo Cevichero in the Costa Editorial direction. The user should feel trust and appetite while moving through a simple one-column WhatsApp ordering flow.

## 2. Art Direction

Mobile-first editorial layout, calm vertical rhythm, generous whitespace, premium food images, short sections and restrained UI. Avoid scaling desktop directly.

## 3. UX Requirements

One-column flow with clear menu access, large touch targets, visible cart access, readable prices and a strong WhatsApp CTA near the order preview.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use Spanish labels such as "Ver menu", "Agregar", "Tu pedido", "Total $260 MXN", "Enviar por WhatsApp". Use realistic seafood products.

## 6. Technical Mockup Requirements

Front-facing mobile landing, 9:16 ratio, no phone device frame, no hand, no perspective, no horizontal overflow, all sections visible.

## 7. Negative Prompt

No phone mockup, no hand holding phone, no browser chrome, no perspective, no lorem ipsum, no cropped sections, no generic app template, no unreadable text.

## 8. GPT Image Adapter

Ask for a flat mobile website screen without device frame. Emphasize that the mobile layout is reorganized for one-column ordering.

## 9. Midjourney Adapter

Use `--ar 9:16`. Say: mobile-first flat landing page UI, no phone frame, no hand, no perspective.

## 10. Flux Adapter

Request a complete mobile landing composition with clear Spanish UI text, product cards, cart preview and WhatsApp CTA.

## 11. Output Filename

`mockups/02-full-landing-mobile.webp`
