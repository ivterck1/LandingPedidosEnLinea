# 03 Hero Desktop - Costa Editorial

## 1. Creative Brief

Explore only the desktop hero for Costa Editorial. The hero must create premium appetite and introduce direct ordering.

## 2. Art Direction

Editorial split rhythm without looking like a generic template: large seafood photography, concise headline, calm supporting copy and two clear CTAs.

## 3. UX Requirements

Primary action: "Pedir por WhatsApp". Secondary action: "Ver menu". Header navigation must remain simple.

## 4. Required Sections

Header and Hero only.

## 5. Content Guidance

Use "El Cangrejo Cevichero", "Mariscos frescos, pedidos sin complicaciones" and plausible short Spanish supporting copy.

## 6. Technical Mockup Requirements

Front-facing desktop hero mockup, no browser chrome, no device, no perspective.

## 7. Negative Prompt

No full page, no browser chrome, no device frame, no lorem ipsum, no generic restaurant hero, no cartoon seafood.

## 8. GPT Image Adapter

Request a desktop hero section only, flat front-facing, with readable short Spanish text.

## 9. Midjourney Adapter

Use a wide aspect ratio such as `--ar 16:9`; specify front-facing website hero, not a browser screenshot.

## 10. Flux Adapter

Prompt for a single refined restaurant hero section with product photography and clear CTAs.

## 11. Output Filename

`mockups/03-hero-desktop.webp`
