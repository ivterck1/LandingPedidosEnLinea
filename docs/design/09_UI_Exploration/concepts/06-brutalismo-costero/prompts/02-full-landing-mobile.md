# 02 Full Landing Mobile - Brutalismo Costero

## 1. Creative Brief

Create a complete mobile landing for Brutalismo Costero. The mobile version must translate bold experimentation into a clear one-column order flow.

## 2. Art Direction

Dark high-contrast mobile interface, bold section breaks, dramatic seafood images, large buttons and simplified hierarchy.

## 3. UX Requirements

Large touch targets, readable prices, clear cart access, visible WhatsApp CTA and no interaction ambiguity.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use "Ordena por WhatsApp", "Agregar", "Tu pedido", "Total $340 MXN", "Nombre", "Recoger", "Domicilio".

## 6. Technical Mockup Requirements

Front-facing mobile landing, 9:16, no phone frame, no hand, no perspective, no horizontal overflow.

## 7. Negative Prompt

No phone mockup, no unreadable dark UI, no tiny buttons, no hidden CTA, no cropped sections, no browser chrome.

## 8. GPT Image Adapter

Ask for a flat mobile landing without device frame, high contrast but readable, all sections visible.

## 9. Midjourney Adapter

Use `--ar 9:16`; specify mobile-first brutalist coastal seafood UI, no phone, no hand, no perspective.

## 10. Flux Adapter

Request bold mobile hierarchy, visible cart, readable form and WhatsApp CTA.

## 11. Output Filename

`mockups/02-full-landing-mobile.webp`
