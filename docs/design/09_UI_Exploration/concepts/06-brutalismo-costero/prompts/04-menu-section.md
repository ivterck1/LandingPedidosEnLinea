# 04 Menu Section - Brutalismo Costero

## 1. Creative Brief

Explore a high-contrast menu section that remains readable and technically plausible.

## 2. Art Direction

Structured brutalist cards, dramatic product images, strong price hierarchy, sharp category labels and clear add buttons.

## 3. UX Requirements

Products must be easy to scan despite the experimental language. Price and action must be clear.

## 4. Required Sections

Categories and Menu preview.

## 5. Content Guidance

Use Ceviche Negro $175 MXN, Tostada de atun $120 MXN, Coctel Bravo $170 MXN, Soda mineral $45 MXN.

## 6. Technical Mockup Requirements

Front-facing section mockup, no device, no perspective, no cropped cards.

## 7. Negative Prompt

No unreadable dark menu, no missing add buttons, no random seafood platter, no lorem ipsum, no chaotic grid.

## 8. GPT Image Adapter

Request a bold high-contrast seafood menu section with readable cards and prices.

## 9. Midjourney Adapter

Use `--ar 4:5`; specify flat brutalist menu UI section, readable Spanish labels.

## 10. Flux Adapter

Request structured dark menu cards, visible categories and add buttons.

## 11. Output Filename

`mockups/04-menu-section.webp`
