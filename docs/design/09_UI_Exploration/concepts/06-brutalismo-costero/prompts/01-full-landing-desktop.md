# 01 Full Landing Desktop - Brutalismo Costero

## 1. Creative Brief

Create a full desktop landing mockup for El Cangrejo Cevichero using the Brutalismo Costero concept. The goal is to test a bold, premium and high-contrast identity while preserving WhatsApp ordering clarity.

## 2. Art Direction

Experimental dark coastal atmosphere, high contrast, bold grid, dramatic seafood photography, strong typography, structured sections and clear conversion anchors.

## 3. UX Requirements

Even with experimental styling, the user journey must remain clear: understand, scan menu, add products, review cart, complete form and send WhatsApp.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use realistic Spanish content: "Mariscos con caracter costero", "Pedir por WhatsApp", Ceviche Negro $175 MXN, Tostada de atun $120 MXN, Coctel Bravo $170 MXN.

## 6. Technical Mockup Requirements

Front-facing complete vertical landing, long portrait ratio around 9:16 or taller, no cropped sections, no browser chrome, no device, no perspective, no presentation board.

## 7. Negative Prompt

No browser UI, no device frame, no unreadable dark text, no nightclub aesthetic, no missing CTA, no hidden menu, no lorem ipsum, no collage.

## 8. GPT Image Adapter

Request a flat full landing mockup with bold high-contrast seafood identity and readable Spanish UI text.

## 9. Midjourney Adapter

Use `--ar 9:16`; specify front-facing full website landing, brutalist coastal seafood, no browser, no laptop, no phone.

## 10. Flux Adapter

Request structured high-contrast sections, dramatic product photography and visible WhatsApp conversion.

## 11. Output Filename

`mockups/01-full-landing-desktop.webp`
