# 03 Hero Desktop - Brutalismo Costero

## 1. Creative Brief

Explore a desktop hero that makes the restaurant feel bold, premium and unexpected.

## 2. Art Direction

High-contrast composition, dramatic seafood image, bold headline, structured navigation and clear CTA.

## 3. UX Requirements

Primary CTA "Ordenar por WhatsApp"; secondary CTA "Ver menu". Impact must not hide action.

## 4. Required Sections

Header and Hero only.

## 5. Content Guidance

Use "Mariscos frescos. Cero complicacion." and short Spanish supporting copy.

## 6. Technical Mockup Requirements

Flat desktop hero, no browser chrome, no device, no perspective.

## 7. Negative Prompt

No unreadable text, no nightclub poster, no laptop mockup, no lorem ipsum, no missing CTA.

## 8. GPT Image Adapter

Request a bold front-facing hero with dramatic seafood photography and readable Spanish CTAs.

## 9. Midjourney Adapter

Use `--ar 16:9`; specify brutalist seafood website hero, no browser UI, no device.

## 10. Flux Adapter

Request high-impact hero with strong hierarchy and visible WhatsApp action.

## 11. Output Filename

`mockups/03-hero-desktop.webp`
