# 01 Full Landing Desktop - Caribe Moderno

## 1. Creative Brief

Create a full desktop landing mockup for El Cangrejo Cevichero using the Caribe Moderno concept. The business goal is direct WhatsApp ordering through a fresh, tropical and contemporary experience.

## 2. Art Direction

Clean tropical layout, bright seafood photography, light section transitions, modern UI rhythm, clear cards and smooth conversion path.

## 3. UX Requirements

The page must move from fresh hero to categories, menu preview, cart preview, customer form and WhatsApp CTA with minimal friction.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use realistic Spanish content: "Frescura caribena lista para pedir", "Ceviche Caribe $165 MXN", "Tostada de camaron $105 MXN", "Limonada mineral $55 MXN".

## 6. Technical Mockup Requirements

Front-facing full vertical landing, long portrait ratio around 9:16 or taller, no browser chrome, no device, no perspective, no presentation board.

## 7. Negative Prompt

No browser UI, no beach postcard background, no childish tropical icons, no lorem ipsum, no cropped page, no generic food template.

## 8. GPT Image Adapter

Request a complete flat landing page with fresh tropical modern seafood identity and readable Spanish labels.

## 9. Midjourney Adapter

Use `--ar 9:16`; specify full landing page, front-facing, no device, no perspective.

## 10. Flux Adapter

Request clean tropical modern sections, realistic seafood content and strong WhatsApp conversion.

## 11. Output Filename

`mockups/01-full-landing-desktop.webp`
