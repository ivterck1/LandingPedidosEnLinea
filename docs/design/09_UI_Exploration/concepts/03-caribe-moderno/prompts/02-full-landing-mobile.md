# 02 Full Landing Mobile - Caribe Moderno

## 1. Creative Brief

Create a complete mobile landing for Caribe Moderno. It should feel like the primary product experience: fresh, light and easy to order.

## 2. Art Direction

One-column tropical modern layout, airy cards, crisp seafood images, clear categories and visible WhatsApp conversion.

## 3. UX Requirements

Large touch targets, no horizontal overflow, quick category scanning, visible cart access, short form and WhatsApp CTA.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use "Ver menu", "Agregar", "Tu pedido", "Total $270 MXN", "Recoger", "Entrega a domicilio", "Enviar por WhatsApp".

## 6. Technical Mockup Requirements

Front-facing mobile landing, 9:16, no phone frame, no hand, no perspective, no cropped sections.

## 7. Negative Prompt

No phone device, no browser UI, no random tropical decoration, no lorem ipsum, no unreadable text, no scaled desktop.

## 8. GPT Image Adapter

Ask for mobile-first one-column seafood ordering page, flat front-facing and no device frame.

## 9. Midjourney Adapter

Use `--ar 9:16`; specify modern Caribbean mobile landing UI, no phone, no hand.

## 10. Flux Adapter

Request clean mobile hierarchy, cart access and WhatsApp CTA.

## 11. Output Filename

`mockups/02-full-landing-mobile.webp`
