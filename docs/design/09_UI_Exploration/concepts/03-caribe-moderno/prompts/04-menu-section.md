# 04 Menu Section - Caribe Moderno

## 1. Creative Brief

Explore a clean tropical menu section optimized for scanning and adding products.

## 2. Art Direction

Light cards, fresh photography, simple category controls, balanced spacing and crisp prices.

## 3. UX Requirements

Products show image, name, short description, MXN price and add button. Categories are visible and easy.

## 4. Required Sections

Categories and Menu preview.

## 5. Content Guidance

Use Ceviche Tropical $165 MXN, Tostada Caribe $98 MXN, Coctel Fresco $150 MXN, Agua de pepino $45 MXN.

## 6. Technical Mockup Requirements

Front-facing UI section, no device, no perspective, no cropped menu.

## 7. Negative Prompt

No lorem ipsum, no unreadable prices, no random burger or pizza, no missing add buttons, no clutter.

## 8. GPT Image Adapter

Ask for clean tropical seafood menu cards with readable labels and MXN prices.

## 9. Midjourney Adapter

Use `--ar 4:5`; specify flat menu section, modern tropical, readable UI.

## 10. Flux Adapter

Request category navigation, clean cards and visible add buttons.

## 11. Output Filename

`mockups/04-menu-section.webp`
