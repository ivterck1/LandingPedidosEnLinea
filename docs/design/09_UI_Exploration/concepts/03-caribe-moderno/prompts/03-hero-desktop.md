# 03 Hero Desktop - Caribe Moderno

## 1. Creative Brief

Explore the desktop hero for a fresh tropical modern seafood restaurant.

## 2. Art Direction

Bright hero, clean composition, seafood and citrus photography, contemporary whitespace and two direct CTAs.

## 3. UX Requirements

Primary CTA "Pedir ahora"; secondary CTA "Ver menu"; clear brand name and short promise.

## 4. Required Sections

Header and Hero only.

## 5. Content Guidance

Use "El Cangrejo Cevichero" and "Mariscos frescos con vibra del Caribe mexicano".

## 6. Technical Mockup Requirements

Flat desktop hero, no browser chrome, no device, no perspective.

## 7. Negative Prompt

No full landing, no beach resort hero, no phone mockup, no lorem ipsum, no generic template.

## 8. GPT Image Adapter

Request a single desktop hero section with readable Spanish text and fresh product photography.

## 9. Midjourney Adapter

Use `--ar 16:9`; specify flat website hero, tropical modern seafood, no device.

## 10. Flux Adapter

Request bright modern hero with seafood photography and clear CTAs.

## 11. Output Filename

`mockups/03-hero-desktop.webp`
