# 04 Menu Section - Mercado Costero

## 1. Creative Brief

Explore a lively menu section that feels abundant but remains easy to scan.

## 2. Art Direction

Colorful category navigation, tactile product cards, fresh ingredient photography and direct prices.

## 3. UX Requirements

Products must include image, name, description, price and "Agregar". Categories must help users navigate without overwhelming them.

## 4. Required Sections

Categories and Menu preview.

## 5. Content Guidance

Use category labels and products: Ceviche Mixto $175 MXN, Tostada Gobernador $120 MXN, Coctel Campechano $165 MXN.

## 6. Technical Mockup Requirements

Front-facing section mockup, no device, no perspective, no cropped cards.

## 7. Negative Prompt

No unreadable prices, no random tacos, no cluttered menu board, no lorem ipsum, no missing add buttons.

## 8. GPT Image Adapter

Ask for an organized colorful seafood menu UI section with realistic Spanish product cards.

## 9. Midjourney Adapter

Use `--ar 4:5`; specify flat menu UI, colorful Mexican coastal, readable prices.

## 10. Flux Adapter

Request category chips, abundant seafood cards and clear add buttons.

## 11. Output Filename

`mockups/04-menu-section.webp`
