# 02 Full Landing Mobile - Mercado Costero

## 1. Creative Brief

Create a complete mobile landing mockup for Mercado Costero. It should feel energetic and local while remaining easy to order from one hand.

## 2. Art Direction

Mobile-first vibrant seafood ordering page, compact lively sections, bold category chips, generous product cards and clear cart access.

## 3. UX Requirements

One-column layout, large touch targets, visible "Agregar" buttons, easy cart preview and clear WhatsApp CTA. Avoid visual overload.

## 4. Required Sections

Header, Hero, Trust strip, Specialties, Categories, Menu preview, Brand story, Cart preview, Order form preview, WhatsApp CTA, Footer.

## 5. Content Guidance

Use Spanish labels: "Pedir ahora", "Agregar", "Tu carrito", "Total $305 MXN", "Enviar por WhatsApp". Include ceviche, tostada and drink examples.

## 6. Technical Mockup Requirements

Flat front-facing mobile landing, 9:16, no phone frame, no hand, no perspective, no horizontal overflow.

## 7. Negative Prompt

No phone mockup, no device frame, no market mess, no unreadable labels, no cropped sections, no generic delivery app.

## 8. GPT Image Adapter

Ask for a complete mobile page without phone frame, with vibrant Mexican coastal identity and clear ordering hierarchy.

## 9. Midjourney Adapter

Use `--ar 9:16`; specify mobile-first flat UI, no hand, no phone, no browser.

## 10. Flux Adapter

Request organized mobile abundance, readable prices and strong WhatsApp CTA.

## 11. Output Filename

`mockups/02-full-landing-mobile.webp`
