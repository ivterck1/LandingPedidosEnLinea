# 03 Hero Desktop - Mercado Costero

## 1. Creative Brief

Explore a desktop hero that communicates lively Mexican coastal seafood and fast WhatsApp ordering.

## 2. Art Direction

Energetic hero with fresh seafood abundance, strong headline, local character and immediate order CTA.

## 3. UX Requirements

Primary CTA "Pedir por WhatsApp"; secondary "Ver menu"; header remains simple and direct.

## 4. Required Sections

Header and Hero only.

## 5. Content Guidance

Use "Mariscos frescos con sabor de costa" and short Spanish copy about ceviches, tostadas and cocteles.

## 6. Technical Mockup Requirements

Flat front-facing desktop hero, no browser chrome, no device, no perspective.

## 7. Negative Prompt

No generic restaurant template, no sombrero cliches, no cartoon seafood, no lorem ipsum, no clutter.

## 8. GPT Image Adapter

Request a lively but organized desktop hero with readable Spanish CTA labels.

## 9. Midjourney Adapter

Use `--ar 16:9`; specify flat front-facing seafood hero, no browser UI, no device.

## 10. Flux Adapter

Request a bold local seafood hero with product photography and conversion CTAs.

## 11. Output Filename

`mockups/03-hero-desktop.webp`
