# Selection Round 2

## Decision

No extended competitive Round 2 was necessary. Antojo Inmediato was refined through five coordinated views:

1. Full landing desktop.
2. Full landing mobile.
3. Hero desktop.
4. Menu section.
5. Cart and order form.

## Refinement Findings

- Keep **“¿Se te antojó? Pídelo ahora”** as the primary hero headline.
- Use the dedicated hero view for composition, product scale and CTA hierarchy.
- Use the full desktop view for overall section rhythm.
- Use the menu view for category navigation and product-card behavior.
- Use the cart/form view for order review and checkout hierarchy.
- Use the mobile image as visual intent only; the final structure must be rebuilt mobile-first.

## Corrections Required Before UI Design

- Unify product names, descriptions, images and prices.
- Recalculate quantities, subtotals and totals from real data.
- Replace illustrative branches, schedules and contact data with confirmed content.
- Define an accessible mobile menu.
- Consolidate the different form versions into one minimum-data order flow.
- Treat generated text and minor visual artifacts as non-binding.

## Status

Refinement complete. Direction approved for wireframes.
