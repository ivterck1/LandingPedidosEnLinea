# Hybrid Directions

## Approved Combination

This is not a hybrid between different concepts. It is a controlled synthesis of five Antojo Inmediato views.

| Source view | Contribution |
| --- | --- |
| Full Landing Desktop | Page architecture and section rhythm |
| Full Landing Mobile | Compact visual language and content priority |
| Hero Desktop | Hero composition, product prominence and CTA hierarchy |
| Menu Section | Categories, product grid and add actions |
| Cart and Form | Order summary, customer details and WhatsApp completion |

## Governing Rule

Antojo Inmediato remains the only primary direction. No secondary concept may dilute its direct, energetic and appetite-led character.

## Guardrails

- Prefer clarity over decorative density.
- Keep WhatsApp green exclusive to conversion actions.
- Use marine illustrations as supporting texture, never as competing content.
- Preserve breathing room around photographs and prices.
- Do not reproduce inconsistencies invented by image generation.
