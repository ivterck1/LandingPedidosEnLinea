# Comparison

## Purpose

This folder stores documentation for comparing Phase 09 visual exploration assets after real images are generated externally.

No image files should be stored here until they contain real visual data. Do not create fake `.webp`, `.png`, `.jpg` or `.svg` placeholders.

## Future Comparison Assets

Future comparison images may be created manually from real mockups and documented with:

- `visual-comparison.md`
- `mobile-comparison.md`
- `component-comparison.md`
- `hant-score.md`

## Evaluation Intent

Comparison should reduce subjective preference by grounding decisions in business goals, user goals, conversion clarity and technical feasibility.
