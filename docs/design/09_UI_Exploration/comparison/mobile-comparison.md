# Mobile Comparison

## Approved Direction

Antojo Inmediato establishes the preferred mobile tone: bold product imagery, compact hierarchy, visible pricing and direct access to the cart.

## Required Translation to Wireframes

- Rebuild for a true phone viewport.
- Use an accessible collapsed navigation.
- Preserve large touch targets and readable supporting text.
- Provide a persistent but non-obstructive cart entry point.
- Stack form fields and reveal secondary information progressively.
- Keep food photography dominant while reducing decorative density.

The generated mobile image is visual evidence, not a literal responsive specification.
